# Eventixar (App)

App Flutter del circuito simplificado: **organizador crea y paga un evento; vendedores y entregadores entran por deeplink**.

Ver el documento de producto: [CIRCUITO.md](./CIRCUITO.md).

## Correr

```bash
flutter pub get
flutter run
```

## Demo

- Login → **Entrar como organizador**
- Crear evento (datos → equipo → cotización → pago simulado)
- En el evento: alta de vendedores/entregadores, asignar rangos, copiar links
- Desde login también: simular deeplink vendedor / entregador
